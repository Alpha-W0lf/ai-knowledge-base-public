# Security Policy

## Reporting Security Issues

If you discover a potential security vulnerability in this project, please report it responsibly rather than opening a public issue.

- Contact: use GitHub private vulnerability reporting on this repository (Security tab → Report a vulnerability).
- Response timeline: Reports will be acknowledged with an initial assessment within 48 hours.

Please include:
- A clear description of the vulnerability and its potential impact
- Reproduction steps or proof of concept
- Affected versions, components, or tools

## Local-First Probing Notes

This repository is built as a **local-first knowledge base**. When auditing or probing this project, consider the following architecture and boundaries:

1. **Read-Only MCP Surface**: The default MCP profile exposes only read-only tools (`search`, `discover`, `get_status`, `get_context`) advertising `readOnlyHint=True`. Data mutation tools (`add_channel`, `sync_now`) are gated behind `AI_KB_MCP_PRIVATE=1` and remain unregistered on the public profile.
2. **Local Storage and Embeddings**: LanceDB operates as an embedded database on local disk (`data/lancedb/`). Vector embeddings are generated by the local Ollama instance (`nomic-embed-text` on `localhost:11434`), or in-process by the offline stub embedder when `AI_KB_EMBEDDINGS=stub`. No documents or queries leave the machine. Outbound traffic is limited to the first cross-encoder load (it downloads the pinned weights from Hugging Face; later loads read the local cache), `ollama pull` at setup, and the optional YouTube sync.
3. **Synthetic Fixtures Only**: Committed test data consists solely of synthetic documents in `fixtures/` and `evals/corpus/`. Private corpora, personal channels, and local transcripts are gitignored (`channels.local.json`, `data/raw/`). Public MCP and CLI responses cite `source_id` or URLs rather than host filesystem paths.
4. **Sanitized Public Errors**: Public MCP tool handlers sanitize error messages to avoid disclosing host filesystem paths or local system environments.
5. **Retrieved Text Is Untrusted Input**: Search results return document text verbatim. With the optional YouTube sync, that text comes from third-party transcripts. Agents should treat it as data, never as instructions. The public profile has no write or network tools, so retrieved text cannot trigger an action through this server.

## Automated Vulnerability Management

GitHub Dependabot checks the Python dependencies and GitHub Actions weekly (`.github/dependabot.yml`).
